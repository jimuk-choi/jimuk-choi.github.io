StowGenie

기여도 70%

StowGenie는 해운 플래너들이 컨테이너 적재 작업을 효율적으로 계획할 수 있도록 돕는 솔루션입니다. 시각화된 인터페이스와 최적화된 적재 제안을 통해 시간과 비용을 절감합니다. 다양한 컨테이너 유형과 선박 조건을 반영하여 오류를 최소화하고 작업 효율을 극대화합니다.

동양시스템즈 UXUI Design, Web Publishing

AS IS PROBLEM

기존 시스템 주요 문제점

배경설명

해운 선사 플래너들이 플래닝 작업에서 여러 불편함을 가지고 있었습니다. StowGenie 프로젝트는 비직관적인 UI, 통합 플랫폼 부재, 실시간 데이터 부족, 비효율적인 커뮤니케이션 등 기존 프로그램의 주요 페인포인트를 해결하고 해운 선사 플래너들의 작업 효율성을 개선하기 위해 설계되었습니다.

비직관적인 UI - 90%

기존 시스템의 UI 디자인이 오래되어 사용자가 시스템을 직관적으로 사용하는 데 어려움이 있습니다. 이로 인해 업무 효율성이 떨어지고, 사용자 경험이 불편해졌습니다.

통합 플랫폼의 부재 - 80%

여러 시스템에서 분산되어 있는 기능들을 하나의 통합된 플랫폼으로 관리하지 못하고, 다양한 프로그램을 사용해야 했습니다. 이로 인해 업무 흐름이 끊어지고, 효율적인 작업 수행이 어려워졌습니다.

가독성이 낮은 데이터 - 75%

실시간 데이터를 확인할 수 있는 워크플로우가 없어, 업무 진행 상태를 한눈에 파악하기 어려운 상태였습니다. 이로 인해 의사결정에 시간이 더 걸렸습니다.

대시보드 부재 - 70%

실시간 데이터를 확인할 수 있는 대시보드가 없어, 업무 진행 상태나 데이터를 한눈에 파악하기 어려운 상태였습니다. 이로 인해 업무 전략 수립에 시간이 더 걸렸습니다.

데이터 분석 도구의 부재 - 65%

복잡한 데이터 분석이 비효율적이고, 데이터를 파악하거나 효율적인 요약 및 수정을 하는 데 많은 시간 소요가 있었습니다. 이로 인해 업무 성과가 최적화되지 않았습니다.

Gamification의 부족 - 60%

게임화 요소가 없어서 직원들의 동기부여가 부족하고, 업무에 대한 참여도가 낮았습니다. 이를 통해 영업 효율성을 높이는 데 어려움이 있었습니다.

TO BE GOAL

프로젝트의 목표

이 프로젝트의 주요 목표는 고객사의 기능적 요구를 충족시키면서 사용자 중심의 새롭고 효율적인 경험을 제공하는 솔루션을 만드는 것이었습니다.

GOAL

브랜딩과 체계적인 UI 구현

브랜딩과 Atomic 디자인을 적용하여 체계적이고 일관된 UI를 구축.

흩어져 있는 여러 시스템 통합

기존 시스템과 새로운 커뮤니케이션 기능, 새로운 솔루션을 결합하여 효율적인 업무 관리를 구현.

통합된 솔루션의 실시간 대시보드 생성

실시간 대시보드를 통해 업무 상태와 영업 성과를 시각적으로 파악하고, 진행 상황을 실시간으로 모니터링.

데이터 시각화로 직관적인 인사이트 제공

가독성 낮은 데이터를 창의적으로 시각화하여 업무 진행 속도를 빠르게 하고, 정확한 의사결정을 지원.

AI 기반 데이터 분석 및 수정

엑셀 기반의 복잡한 데이터 처리에서 벗어나, 생성형 AI를 활용해 원하는 데이터와 통계를 빠르게 얻고 수정할 수 있는 시스템을 제공.

업무에 게임 요소 추가로 동기부여 증진

플래닝 업무에 게임 요소를 추가하여, 업무에 즐거움을 주고, 직원들의 동기부여를 향상.

주요 해결방안

브랜딩을 통한 UI 디자인 혁신

브랜딩을 바탕으로 Atomic 디자인 방법론을 적용하여 각각의 UI 요소를 일관되게 연결하고, 효율적으로 디자인합니다. 이를 통해 직관적인 사용자 경험을 제공하고, 업무 효율성을 극대화합니다.

#SOLUTION-01

커뮤니케이션과 업무 관리의 혁신적 결합

기존 솔루션과 새로운 방식의 커뮤니케이션 기능, 업무관리 솔루션(Workflow)을 추가하여 업무 흐름을 원활하게 합니다. 이를 통해 업무 효율성과 협업을 대폭 향상시킵니다.

#SOLUTION-02

실시간 대시보드와 개인화된 위젯 관리

사용자는 선박별 Workflow, 커뮤니케이션 현황, 배의 위치 등 실시간으로 확인할 수 있으며, 위젯 형식으로 개인 맞춤형 커스터마이징이 가능합니다. 이를 통해 업무 상황을 한눈에 파악하고, 효율적인 관리와 업무 최적화를 지원합니다.

#SOLUTION-03

선박 일정 시각화 및 직관적 업무 관리

선박 일정을 시각화하여 타임 프레임을 한눈에 쉽게 수정할 수 있게 하고, 업무 상태를 색상으로 직관적으로 표현하여, 업무 진행 상황을 빠르게 파악하고 효율성을 높입니다.

#SOLUTION-04

생성형 AI로 데이터 분석 및 실시간 수정

생성형 AI를 결합하여, 엑셀에서 다루기 힘든 복잡한 데이터를 AI를 통해 분석하고 원하는 정보를 실시간으로 생성 및 수정할 수 있게 합니다. 이를 통해 데이터 분석의 효율성을 높이고, 의사결정 속도를 대폭 향상시킵니다.

#SOLUTION-05

업무 처리에 게임화 요소 도입

랜덤으로 업무 처리하는 과정에 아이템 요소를 추가하여, 업무 등급을 정하고 상품을 제공하는 방식으로 직원 참여도와 업무 동기부여를 높입니다. 이를 통해 업무 효율성과 직원 만족도를 향상시킵니다.

#SOLUTION-06
